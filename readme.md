# World of Warcraft

An epic-fantasy theme inspired by *World of Warcraft* — Blizzard gold on a deep
arcane night sky, with distant mountain silhouettes and a glowing crest.

## Palette
- **Accent:** Blizzard gold `#f5b942`
- **Surfaces:** deep arcane navy/slate (`#0b111c` → `#141f33`)
- **Item-rarity nods:** legendary orange `#ff8000`, epic purple `#a335ee`,
  arcane blue `#3fa9f5`
- Light mode is a parchment/tavern variant: aged-paper surfaces with a burnished
  gold accent.

## Backdrop
A subtle, non-distracting landscape — layered mountains under a moonlit arcane
sky — baked into the background and the chat surface. Kept faint so it never
competes with the conversation.

## Fonts
- **Sans / body:** EB Garamond (400/500/600) — an elegant, highly readable serif
  that carries the fantasy tone without hurting long-read legibility
- **Mono / code:** Space Mono (400)
- The ornate two-tier WoW-style lettering (Cinzel) lives in the crew logo image,
  not the chat body, so daily reading stays crisp.

All fonts are SIL Open Font License 1.1 (see `LICENSE.txt`).

## Logo
`branding/logo.png` — a WoW-style ornate gold badge with the purple Kiro ghost
crest and a "KIRO CREW / WARCRAFT" gold wordmark.

## Install
Settings → Display → Install theme → point at this folder.
